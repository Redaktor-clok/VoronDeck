# VoronDeck · Правила общения

Здесь обсуждают экран, помогают воспроизводить ошибки и предлагают улучшения. Приветствуются участники с любым опытом.

## Как общаемся

- Обсуждаем решения и поведение программы, уважительно относимся к людям.
- Пишем по существу, приводим примеры и помогаем уточнить проблему.
- Не допускаем оскорблений, угроз, дискриминации, травли и спама.
- Не публикуем чужие личные данные, пароли, ключи и токены.
- Не предлагаем опасные проверки нагрева или движения без объяснения условий и рисков.

Правила действуют в Issues, pull request и других обсуждениях этого репозитория.

## Если возникло нарушение

В публичном обсуждении можно обратиться к [@Redaktor-clok](https://github.com/Redaktor-clok), приложив ссылку на комментарий без повторной публикации личных данных. Для конфиденциальной жалобы используйте меню GitHub **Report content** у сообщения.

Владелец проекта рассматривает обращения с учётом контекста. Нарушающие правила сообщения могут быть скрыты или удалены; при повторных или серьёзных нарушениях участие может быть ограничено.
